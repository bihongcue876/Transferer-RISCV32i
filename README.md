# RISC-V 转码学习助手

> RISC-V (rv32i) 转码与学习桌面工具

- **研发与项目管理**：BiHongCue
- **目的功能**：辅助学习、模拟转码、帮助基于汇编指令与机器码的复习、方便应用和补丁。


## 项目呈现

- 使用 **Python + Tkinter** 构建跨平台桌面应用
- 底层文件 `core/isa_rv32i.py` 实现完整的 RV32I 指令编码/解码逻辑
- 支持汇编 ↔ 十六进制 ↔ 二进制三向互转，支持大小端切换
- **支持标签（label）与两遍汇编**：分支/跳转可直接引用标签，`la`/`call`/`tail` 按真实工具链方式展开为 `auipc + addi/jalr`
- **逐行错误提示**：无法汇编的行红色高亮，并显示具体原因（未知指令/无效寄存器/立即数越界/未知标签等）
- 交互式学习页面，涵盖 R/I/S/B/U/J 六类指令 + Zicsr 特权指令 + 系统指令 + 常用伪指令
- 学习部分每条指令附带可运行的三框测试块，互相呈现代码结果，有效辅助学习
- 机器码列支持编辑，按 Enter 或自动反编译为汇编代码（支持一行多条指令的正确拆分）
- 底部面板提供全局统计（总行数/字节数/错误行数）和内存布局配置，地址按每行实际字节数推进
- **零依赖单元测试**（标准库 unittest）：编码/解码往返、已知向量、标签解析、伪指令展开全覆盖

**支持指令集**：42 条 RV32I 基础指令 + 6 条 Zicsr 特权指令 + 3 条系统指令 + 25 条伪指令

**项目结构**：
```
transfer-riscv32i/
├── main.py                  # 应用入口
├── core/                    # 核心部分（指令编码/解码引擎 + 两遍汇编器）
├── ui/                      # 用户界面（首页/转码/学习/帮助）
├── tests/                   # 单元测试（python -m unittest discover -s tests）
├── resource/                # 图像资源（GIF 格式）
└── docs/                    # 设计文档（不予上传）
```

## 项目使用

### 方式一：可执行包

- 从发布页下载对应平台（Windows / Linux / macOS）的打包程序
- 解压后直接运行 `main.exe`（或对应可执行文件）

### 方式二：开源代码

```bash
# 1. 复制仓库
git clone https://github.com/your-repo/transfer-riscv32i.git
cd transfer-riscv32i

# 2. 虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

# 3. 安装依赖（当前无依赖）
# 4. 运行测试
python -m unittest discover -s tests

# 5. 启动
python main.py
```

### 依赖说明

纯 Python 标准库 + Tkinter，**无外部依赖**。图片资源使用 Tkinter 原生支持的 GIF 格式，无需 PIL/Pillow。

## 快速上手

1. **转码页**：左侧输入汇编代码（如 `add x1, x2, x3`），右侧自动显示对应机器码（十六进制/二进制），可调整大小端顺序。支持标签与两遍汇编（`loop:` / `beq x1, x2, loop` / `la x6, data`）。机器码列支持编辑换行，修改后自动反汇编回汇编列。错误行红色高亮并在底部显示原因。底部面板可查看全局统计和配置内存布局。
2. **学习页**：左侧导航树选择指令类别（系统指令→特权指令→六类指令→伪指令），右侧显示指令文档。每条指令下的 **「试试看」** 测试块可三向互转验证编码，出错时显示具体原因。
3. **帮助页**：查看快捷键、标签用法、大小端说明、缓存机制等使用说明。
4. **首页**：作为封面，概览功能区，支持清除缓存重置状态。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存当前状态到缓存 |
| Ctrl+Q | 退出程序 |
| Ctrl+Shift+N | 清空转码页内容 |
