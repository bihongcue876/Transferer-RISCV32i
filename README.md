# RISC-V 转码学习助手

> RISC-V (rv32i) 转码与学习桌面工具

- **研发与项目管理**：BiHongCue
- **目的功能**：辅助学习、模拟转码、帮助基于汇编指令与机器码的复习、方便应用和补丁。


## 项目呈现

- 使用 **Python + Tkinter** 构建跨平台桌面应用
- 底层文件 `core/isa_rv32i.py` 实现完整的 RV32I 指令编码/解码逻辑
- 支持汇编 ↔ 十六进制 ↔ 二进制三向互转
- 交互式学习页面，涵盖 R/I/S/B/U/J 六类指令 + Zicsr 特权指令 + 常用伪指令
- 学习部分每条指令附带可运行的三框测试块，互相呈现代码结果，有效辅助学习

**项目结构**：
```
transfer-riscv32i/
├── main.py                  # 应用入口
├── core/                    # 核心部分
├── ui/                      # 用户界面
├── resource/                # 图像资源
└── docs/                    # 设计文档（不予上传）
```

## 项目使用

### 方式一：可执行包

- 从发布页下载对应平台（Windows / Linux / macOS）的打包程序
- 解压后直接运行 `main.exe`（或对应可执行文件）

### 方式二：开源代码

```bash
# 1. 复制仓库
git clone https://github.com/your-repo/transfer-riscv32i.git
cd transfer-riscv32i

# 2. 虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

# 3. 安装依赖（当前无依赖）
# 4. 启动
python main.py
```

### 依赖说明

纯 Python 标准库 + Tkinter，**无外部依赖**。图片资源使用 Tkinter 原生支持的 GIF 格式。

## 快速上手

1. **转码页**：左侧输入汇编代码（如 `add x1, x2, x3`），有意识地控制地址，右侧自动显示对应机器码（十六进制/二进制），可调整大小端顺序。修改机器码后回车也会经反汇编呈现在汇编。
2. **学习页**：左侧导航树选择指令类别，右侧显示指令文档。加载可能有点慢，点击每条指令下的 **「试试看」** 测试块，可三向互转验证编码。
3. **首页**：作为封面，概览功能区，支持清除缓存重置状态。
